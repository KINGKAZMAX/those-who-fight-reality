## 当前美术范围

- 4 位原创伙伴与纸卷怪各有一张 4×4 透明表，共 80 个独立姿态。引擎复用姿态生成 65 张运行图集、3459 个映射格；这些不是 3459 张独立动画。
- 三处背景已经用于战斗，场景中的章节巨像、门框首领并未实装。高中场景、四学段完整剧情、角色年龄变化、专属新动作与新音频仍未完成。
- 游戏当前为蓝色校园像素界面；旧荧光黄都市 UI 已归入历史页。
- PNG 均直接上传自 `vendor/F.LF/game/art/`，未在本次 Figma 同步中重新生成图片或调用付费模型。当前 2D 机制不需要 Tripo。
- 运行端字体为 Courier New / 系统中文；Figma 审阅文档使用 Noto Sans SC。此板用于内容与资产检索，不是游戏 UI 的像素复刻。
