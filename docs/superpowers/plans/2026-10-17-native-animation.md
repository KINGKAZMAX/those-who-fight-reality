# LF2 逐帧动画替换计划

目标：取消16姿态映射；每个原生 pic 独立引用原网格中的对应画格，保持动画数据与锚点不变。

架构：以原始完整图集作为动作模板，按图集重绘校园身份；运行时只替换整张图集路径，绝不按动作名称选择16姿态。为原图和候选图逐格比较数量、透明边界和锚点位置。未验收的候选图不进入正式资源。

技术：AMD / Canvas / 原版 LF2_19 data，内置 image_gen，Node/Playwright 验收。

- [x] 清点所有角色、武器、弹体图集与原始 pic 引用，建立逐图集资产清单。
- [x] 用原版完整精灵表与原创角色参考重绘。先验收小一基础70格，确认生成能保持网格、朝向、倒地与翻滚动作。
- [x] 建立完整图集接入模块与失败测试，保留 pic、wait、next、center、bdy、itr、wpoint、opoint，拒绝缺图或尺寸错误。
- [x] 对候选图集做逐格透明边界对照；通过后扩展其余原生图集。
- [x] 全角色整套动画与剧情/自由对战回归，检查截图、帧率、技能事件和控制。

完成标准：图集无缺格、无16姿态回退；原图逐格对应与数值数据完全保留。若生成无法保持原动作，不把仅格数匹配当成通过，不宣称已全完成。
