# 四角色完整技能实现计划

目标：把当前四位伙伴的全部17个站立主动招式与原有派生连招变成清楚、可操作、可验证的完整技能体验。用户已要求「所有技能都要加上」，沿用已确认角色与战斗风格。

架构：新AMD技能模块维护技能资料和双人快捷输入，使用原控制器缓冲形成原生组合；独立UI提供出招表和快捷条。现有战斗引擎负责伤害、消耗、施法时机，校园包限定合作修正与满蓝开局。技能表现继续用生成透明精灵图适配现有对象。

- [x] 对照四份角色数据和依赖逐项审计17技能、MP、续发与派生动作。
- [x] 新增 reality-skills.js：P1 Q/E/R/T/Y、P2 U/I/O/[/]；基础自定义冲突时回退到组合；暂停、失能、缺蓝与长按保护；两位玩家独立。
- [x] 新增 reality-skills-ui.js/.css：全技能表、根据实际改键显示组合、技能快捷条、自动暂停/恢复与键盘焦点处理。
- [x] 新增技能特效透明图并接入：区分治疗、护盾、攻击、旋盘、冻结、冰柱、旋风、武器及射弹。
- [x] 校园包限定修正：笛音只控敌，治疗只治疗同队；四英雄满蓝开局。
- [x] 集成入口、快捷键状态与可测试游戏状态；验证17个实际入口、MP及产物、派生与协作效果。
- [x] 检查正常双人操作、改键、技能面板、暂停、重开、截图和资源错误；更新操作说明与验证记录。

范围：保留原生招式机制和派生输入，不添加未公开角色的变身合体、不把世界观关卡任务作为战斗技能。基础移动、攻击、跳跃、防御不改变。
