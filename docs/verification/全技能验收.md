# 四角色完整技能验收

> 历史记录：本文记录最初的单键技能方案。当前版本已改成 LF2 原生组合键，最新验收见 [组合键验收](组合键验收.md)。

日期：2026-10-17。范围：当前四位伙伴的全部 17 项专属技能、原生续招入口、双人快捷操作、技能表与校园特效。

## 实装内容

- 小一 4 招、林夏 5 招、周齐 4 招、陈野 4 招；故事与自由对战共用。
- P1 Q / E / R / T / Y，P2 U / I / O / [ / ]。快捷键通过原生组合检测器施放，原引擎决定时机、耗蓝和命中。保留基础改键；冲突格停用并提示。
- 完整出招表显示实际玩家键位、耗蓝、续招及进阶技巧。打开自动暂停，关闭恢复原状态；Esc 关闭技能表而不退出对战。
- 双人可点击技能栏位于战场外，小窗口隐藏技能栏并保留顶部入口。
- 新增 16 格透明技能特效图集，映射治疗、结界、回旋弹、冻结、冰柱、旋风、召唤武器、箭矢、升龙、连拳和笛音。10 张源 PNG 共生成 65 张运行图集、3459 个映射格。
- 校园键盘角色满 500 MP 开局，后续按原规则消耗与恢复。普通近战和专属技能不直接伤害同队伙伴；被击飞的身体仍保留原生间接碰撞。治疗只给同队，恢复预算准确为最多 100 HP，且不越过可恢复上限。
- 修复缺省箭矢音效导致异常、首次笛声浮空缺少攻击来源导致身体碰撞异常。保留已存在的音频播放兼容修正及第一章功能。

## 最终验证

- `node --test tests/*.test.cjs`：**56/56 通过**，包含键位、技能组合、合作伤害、治疗、召唤、音效及现有章节回归。原始输出见 [测试记录](skills-unit-tests.txt)。
- `tools/verify_reality_skills.cjs`：**17/17** 实际键盘施放通过；逐招核对原生入口、MP 消耗和相应生成对象，治疗确实回血、召唤武器确实握持、笛声确实控敌。另验双人同一时刻各耗 40 MP、原生组合与续发共耗 80 MP。[逐招报告](skills/report.json)。
- `tools/verify_reality_skills_ui.cjs`：**9 组 UI 检查通过**；四角色技能数 4/5/4/4、实际双人键位、冲突回退、暂停恢复、输入隔离、缺蓝提示、大小窗口布局。[UI 报告](skills-ui-report.json)。
- 双人基础操作回归通过：同时移动、跳跃、防御、攻击，暂停/继续、返回、改键保存、三场景、8 人对战、击倒结算和 demo。[回归报告](skills-regression/reality-browser-report.json)。此次并行测试期间 8 人 FPS 采样为 30/30/30/30/30/30/24/30，不作为长期性能保证。
- 技能实机、UI 和基础操作的最终运行均无页面异常或失败资源响应。浏览器选择音频源或 seek 造成的 `ERR_ABORTED` 媒体取消单独记录，不计为加载失败。
- develop-web-game 提供的浏览器客户端已重新运行并进入第一章实际战斗，完成双人移动输入，查看了 [最终截图](skills-client-final/shot-0.png) 与 [文本状态](skills-client-final/state-0.json)，没有控制台错误文件。
- `tools/check_reality_art.cjs` 检查通过：10 张源 PNG、34 张角色图集、31 张道具/特效图集、3459 个映射格。已查看技能表、双人栏、小窗口、治疗、风暴、武器与笛声实机图。

逐招检查关闭敌方 AI、设置站位和生命值，以隔离技能效果；施放仍使用实际键盘输入，没有用直接换帧替代施放。笛声友军检查将同伴放在施法半径内、敌人身体碰撞范围外。完整难度与两位真人的实体键盘长期体验尚未验收。
