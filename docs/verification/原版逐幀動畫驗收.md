# 原版逐幀動畫接入 · 2026-10-18

這一版的遊戲運行路徑不再依動作名稱選擇16姿態，而是沿用原生 `frame.pic`，逐格讀取完整圖集。範圍為目前可選的六位伙伴、三種怪物，以及全部已引用的武器、飛行物、命中與碎片特效。

## 接入數量

- 57張生成圖集：角色與怪物27張，武器與特效30張。
- 1930個原生圖片編號逐一對應；1881格有可見像素，其餘維持原生透明／消失狀態。
- 32格單幀補圖：修正明顯背身朝向、舉手、缺失受擊、紀律尺旋轉角度、碎片與消散格。
- 六位伙伴與三怪物本身覆蓋1405個圖片編號，其中1396格可見；不將1930或1881誤稱為角色數或獨立手繪原畫數。
- 保留14張原生來源圖集：四位目前沒有開放選取的上游角色共13張，以及一張沒有被任何動作引用的兼容圖集。這不代表把整個LF2原始角色名單都新增為可選校园伙伴。

## 對齊方式

`game/reality-art.js`只準備場景與身份參考／頭像；正式入口傳入 `nativeAnimation:true`，跳過舊16姿態與靜態特效的圖集製作。接著 `game/native-animation.js` 逐張替換完整圖集，保持原 `pic`、網格、左右翻轉、錨點和時間線。

原始 `wait`、`next`、`centerx/centery`、`bdy`、`itr`、`wpoint`、`opoint`與bmp物理欄位均不因動畫替換修改。缺少圖片或必要動作格時整批拒絕接入，不能靜默回退到16姿態。

角色與武器重繪格按原格可見範圍校正位置與尺寸；縮小時保留細手腳與尖端，避免普通最近鄰採樣吃掉肢端。特效與碎片另外套用原生每像素alpha和亮度上限，保留原有的擴散輪廓、消失節奏與細線，同時使用新生成素材的色彩。原版瞬移pic188的一個深色像素直接保留，不捏造一個人物站姿填入。

本版為原圖作姿勢模板的AI重繪，不是對原圖逐像素人工描摹。像素範圍、透明度、圖片編號與時序可程式驗證；這些檢查不能單獨證明每一處關節角度完全相同。製作時另以原圖／新圖人工檢視，對發現的明顯錯誤另作32格補圖；不把單純格數匹配當作姿勢正確的證據。
