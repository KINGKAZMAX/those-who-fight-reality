# LF2 原生组合键验收

## 修改范围

- 17 招全部使用 LF2 原生顺序组合输入，不再提供额外单键或点击施放。
- 技能模块只读取角色、键位、MP 与当前动作，供出招表和战斗提示显示，不再写入控制器输入。
- 原角色对应：小一/Davis、林夏/John、周齐/Freeze、陈野/Henry。招式帧、命中、耗蓝和连招窗口保留原规则。
- 双人出招表按实际改键显示；横向方向二选一决定出招方向；持续走动时需松方向后重新输入。
