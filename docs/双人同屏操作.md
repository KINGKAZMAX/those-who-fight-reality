# 一台 Mac，两个人一起玩

《与名为现实的怪物战斗的人们》当前支持两位玩家共用一台 Mac 的键盘，同屏组队对抗纸卷怪。推荐方案使用普通字母键与方向键，不需要数字小键盘或 Fn 组合键。

## 开始双人合作

1. 双击项目中的 `启动LF2试玩.command`，保留终端窗口，并打开 [本地试玩](http://127.0.0.1:18765/F.LF/game/game.html)。
2. 点击「一起出发」。人数默认是「双人同屏合作」。
3. 点击 P1 标签，为玩家一选择伙伴；再点击 P2 标签，为玩家二选择伙伴。也可以选择同一个角色。
4. 默认「01 故事 · 不要掉队」，点击章节出发按钮，阅读开场后一起走进校门。
5. 如需自行选择 1–6 只怪物与校园场景，切换「自由对战」再点击「准备好了 · 出发」。两位玩家属于同一队。

当前可选伙伴为小一、林夏、周齐和陈野。三处场景分别是「小学 · 不要掉队」「初中 · 名次巨像」「大学 · 前途无量」。

## 推荐键位

| 动作 | 玩家一（P1） | 玩家二（P2） |
| --- | --- | --- |
| 向上移动 | W | ↑ |
| 向下移动 | S | ↓ |
| 向左移动 | A | ← |
| 向右移动 | D | → |
| 攻击／拾取 | F | J |
| 跳跃 | G | K |
| 防御 | H | L |

玩家一使用 **WASD + FGH**；玩家二使用 **方向键 + JKL**。上下移动是在场地前后方向走位，跳跃使用独立按键。

| 共用操作 | 按键／入口 |
| --- | --- |
| 暂停、继续对战 | P，或顶部「暂停／继续」按钮 |
| 退出当前对战、回到选角 | Esc，或顶部「退出」按钮 |
| 选角完成后出发 | Enter，或「准备好了 · 出发」按钮 |

F1 仍可暂停。使用推荐键位时，直接按 P 即可。

## 双人技能

四位伙伴的 **17 项专属技能已全部开放**，像 LF2 原角色一样使用连续组合施放。`›` 表示依次快速按下，不用同时按住。例如小一「草稿冲击」：P1 **H › A/D › F**，P2 **L › ←/→ › J**。中间的左右方向键二选一，决定出招方向，不需要预先转身。林夏有 5 招，其他伙伴各有 4 招。

每次本地对战开始，键盘玩家拥有 **500 MP**，施放后按原生规则正常回蓝。技能保留各自消耗、续招和动作限制；站稳后输入最容易成功。林夏可治疗同队伙伴，陈野的午后笛声只控制敌人。

在主页或选角页点击「全技能出招表」，或点击战斗顶部「技能」，可切换 P1 / P2 查看当前实际组合键、效果、耗蓝和派生。战斗中查表自动暂停，关闭时恢复之前的暂停状态；Esc 会先关闭出招表。底部技能栏只显示出招提示，点击不会施放技能。小窗口会隐藏提示栏，组合输入与顶部「技能」入口仍然有效。

修改基础键位后，游戏内出招表和战斗提示会自动更新为当前组合。两位玩家可各自输入组合，同时出招。持续走动时，先松开方向键再输入完整组合；已经按住的同一个键不会算作新的输入。

17 招默认组合、续发与进阶技巧见 [完整技能与连招](完整技能与连招.md)。预览：[出招表](verification/skills-guide.png)、[双人技能提示栏](verification/skills-battle-ui.png)。

## 修改键位

1. 在主页点击「双人键位」，或在选角页点击「修改键位」。
2. 在表格中找到对应玩家和动作，点击当前显示的按键。
3. 按一下想使用的新键。修改成功后会显示保存提示；按 Esc 可取消本次修改。
4. 两位玩家不能共用同一个按键，同一玩家的两个动作也不能共用一个按键。若发生冲突，界面会说明该键正被哪位玩家的哪个动作使用，可继续按另一个键。
5. 修改完成后点击「保存并返回」。有效修改已即时保存在当前浏览器中，之后刷新页面仍会使用这套键位。

可使用字母、数字、方向键、空格或标点键。P、Esc 和功能键保留给暂停、退出等快捷操作；改键时使用单个按键，不使用 Command、Control 或 Option 组合键。

如果想交换两个已被占用的按键，先把其中一个动作临时改到空闲键，再依次完成交换。

## 恢复推荐方案与已有设置

点击设置页的「恢复推荐双人键位」，即可恢复并保存上表的 **WASD + FGH / 方向键 + JKL**，无需逐项修改。

首次进入，或之前仍使用 LF2 原版默认键位时，会自动采用推荐方案。**之前已经定制过的键位会保留，不会被本次更新覆盖。** 选角页、设置表和战斗底部提示显示当前实际键位。

如果旧自定义把 P 用于攻击等动作，该动作仍然有效，暂停改用 F1 或顶部按钮；恢复推荐方案后，P 会重新用于暂停。设置保存在当前浏览器、当前本地游戏地址中；更换浏览器或清除站点数据后需要重新设置。

## 当前试玩范围

本次提供 4 位原创伙伴、3 处校园背景与纸卷怪合作对战。原创角色、场景与道具外观已经接入游戏；动作逻辑、招式判定与音频继承 F.LF / LF2。

第一章「不要掉队」已接入广播开场、两段遭遇、援护、检查点与合照收藏。在故事模式中靠近倒下的伙伴，持续按住自己的防御键 1.5 秒，可恢复伙伴 180 HP；暂停不会继续累计。所有玩家都倒下时，可从本段重试。自由对战仍使用原规则。

第一段通过后保存检查点，刷新后可以继续；第二段完成后保存「第一张合照」。进度保存在当前浏览器，不跨设备同步。完整升学流程、考试、章节首领与毕业结局仍待制作。详见 [第一章试玩](第一章试玩.md)。
