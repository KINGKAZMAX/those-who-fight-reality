# 失物招领局：末班归还

2026-10-17 · 世界观与制作提案，尚未实现原创关卡或换皮。

## 世界观

上海最后一班列车进站前，地下失物中转站的物件开始苏醒。没人认领的伞、玩具和行李箱，被遗忘得越久，脾气就越大。两名临时工必须在三分钟内制服它们、贴上归还标签，把它们送上末班车。

玩家不是消灭怪物，而是帮助失物重新找到主人。每场胜利留下一张简短的失物记录，让热闹的街机乱斗带一点人情味。

### 角色与首关

- **拆箱员**：近战，使用封箱锤，擅长冲刺撞击、抓取和投掷。
- **贴签员**：远程，使用贴签枪，以短暂定身和范围标记协助队友。
- **首关：末班中转台**。一张固定横版场景，两波普通失物，再出现由遗失箱堆成的头目。胜利目标是完成归还，失败条件是生命耗尽或时间到。
- **最快可玩切片**：先完成一名玩家角色、一种敌人、一个场景及完整开局—战斗—结算；第二角色与波次脚本放到随后一轮。当前安装的 F.LF 只作为原版 VS 试玩，以上规则仍需开发。

不同风格的现成图片可以成为来自不同主人的失物，但角色身体比例、光照方向与游戏内轮廓仍要统一。当前目录尚未发现用户此前生成的图片，因此本提案不假定它们的具体风格。

## 路线选择

| 路线 | 适用情况 | 本次判断 |
| --- | --- | --- |
| F.LF 浏览器版 | 迅速本地试玩，修改 HTML/CSS UI、精灵图与角色数据 | 首选；已下载到本项目 |
| OpenLF2 原生 Mac 版 | 更完整的 LF2 模式，使用 Lua/mod 修改 | 后续备选；需原版 v2.0a 安装包，本次未安装 |
| 新做实时 3D 游戏 | 必须展示实时 3D 角色的情况 | 制作与性能验证工作显著增加，不作为首个试玩版本 |

官方 LF2 Remastered 现已列出 macOS 支持，可用于体验原作。社区开源实现更适合修改代码。F.LF 代码标为 GPL-3.0，OpenLF2 代码标为 MIT；这些代码许可不应被当成原作图片、声音的授权。

## Tripo 用在哪里

**判断：快速试玩不依赖 Tripo；黑客松展示值得用 Tripo 做 1—3 件有辨识度的旧物或武器。**

推荐流程：已有图片 → Tripo 生成模型 → 检查形状与贴图 → 必要时减面 → 固定视角预渲染 PNG/动作图集 → 放入二维游戏。3D 原件保留用于展示或后续实时 3D 版本。

| 资产 | 首版处理 | 是否需要 Tripo |
| --- | --- | --- |
| 头像、封面、背景、技能图标 | 直接使用用户已有图片，裁切并统一风格 | 不需要 |
| 遗失箱、雨伞、武器、站台摆件 | 少量模型，固定镜头渲染为精灵 | 推荐 |
| 完整玩家角色与头目 | 待机、跑动、攻击、跳跃、受击、倒地及锚点全部对齐 | 后置 |
| UI 按钮、生命条、任务计数 | 可编辑矢量图形与文字 | 不需要 |

单张立绘不能直接替换整套战斗动作。Tripo 的模型生成、绑骨、动作适配和精灵渲染是不同工序；模型生成成功不等于角色已能战斗。首版不在战斗中请求生成接口。

作为待验证的制作预算，道具可从 1,000—3,000 面、1K 贴图起步；若后续做实时角色，再从每角色 5,000—10,000 三角面及单材质起步，按实机表现调整。预渲染成二维图后，战斗负载主要由精灵尺寸、数量、特效与逻辑决定，不由源模型面数直接决定。

## UI 方向

使用**票据米白、墨黑、朱红印章**，结合行李标签、档案编号与旧站台标识。Figma 中保留可编辑文字和图形。

- 主菜单：大标题、现有主视觉、“开始值班”与“操作说明”。
- 选角：角色立绘搭配行李票卡，突出角色名称与操作倾向。
- 战斗：头像、生命、体力靠上；归还数量与剩余时间居中；底部仅显示必要操作。
- 结算：显示本局找回的失物和一条主人的短留言。

## 流畅性验收

F.LF 原版 `LF/global.js` 的逻辑帧率为 30。把计时器改成 60 会改变游戏速度，不能作为优化方法。当前方案保留原作节奏；未来如果需要 60 Hz 绘制，应单独实现逻辑与渲染解耦及插值。

原创资产版本的验收目标：资源进入战斗前加载；首版最多 6 个同时活动角色；特效数量设上限；同场景连续战斗 3 分钟不持续跌帧；复测加载、移动、攻击、受击、跳跃与结算。目标不等于已经达到，换入素材后必须再测。

## 本地文件

- `vendor/F.LF/`：上游网页游戏源码。
- `vendor/LF2_19/`：原版参考图片、数据和声音。
- `assets/source/`：用户已有图片接收目录，目前未导入。
- `assets/tripo/`：以后生成的 3D 源资产。
- `assets/runtime/`：供游戏使用的精灵图与图集。
- `assets/catalog.csv`：可检索资产台账，区分计划、参考和真实文件。
