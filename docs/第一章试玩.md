# 第一章：不要掉队

这是最新世界观的首个可玩故事片段，使用已经确认的校园像素资产。广播响起：“新同学，请不要掉队。”玩家与伙伴清开挡路的纸卷怪，一起走进前程市小学。

## 进入故事

1. 打开 [本地游戏](http://127.0.0.1:18765/F.LF/game/game.html)，点击「一起出发」。服务器未启动时，先双击项目中的 `启动LF2试玩.command`。
2. 保持「01 故事 · 不要掉队」，选一人或双人，再为 P1、P2 选择伙伴。
3. 点击「第一章 · 不要掉队」，阅读开场后点击「一起走进校门」。

| 动作 | P1 | P2 |
| --- | --- | --- |
| 移动 | WASD | 方向键 |
| 攻击 / 拾取 | F | J |
| 跳跃 | G | K |
| 防御 / 援护 | H | L |

**援护：** 走到倒下的伙伴身边，按住自己的防御键 **1.5 秒**，直到进度条完成。伙伴恢复 180 HP，短暂受到保护。松开防御或离开范围会重置进度。暂停时不会继续累积。

战斗中按 P 暂停 / 继续，Esc 返回选角。自定义按键以游戏显示为准。剧情面板中的 Enter 确认、Tab 切换按钮、Esc 返回选角；完整键位说明见 [双人同屏操作](双人同屏操作.md)。

## 两段路与一个纪念物

- **第 1 段：校门口。** 两只纸卷怪；清开它们并扶起所有伙伴后，进入中途休息，自动记录检查点。
- **第 2 段：一起进教室。** 三只纸卷怪；开始时恢复玩家体力。通过后听到老师说“先坐下，名字慢慢写。”，收藏「第一张合照」。

单人倒下或双人全部倒下时，选择从当前这段重试。失败不会删除已经到达的检查点或合照。两段都使用小学背景，第二段尚未制作独立教室场景。

存档保存在当前设备、当前浏览器、当前游戏地址中。第一段完成后刷新，主页会显示「继续第一章」；通关后可重新从第一段游玩，合照仍保留。更换浏览器或清除站点数据不会带走这里的存档。若存储不可用，游戏会显示提示，保留当前页面仍可继续。

## 自由对战

选角页点击「自由对战」，可选择三处校园场景、1—2 位玩家及1—6只纸卷怪。这个模式沿用原有对战和结算规则；故事检查点、双人援护与合照只在第一章生效。

## 当前边界

本章是世界观的第一段可玩验证。考试与升学流程、反向传送带机关、角色年龄变化、独立章节首领及毕业礼物结局仍待制作。「第一张合照」是本章纪念物，与毕业时归还给角色的礼物不同。
